# 技术选型说明（为什么这么选）

> 这份文档解释本项目相对原始需求文档做的取舍。原则只有一条：**先用最短路径跑通闭环，再按需升级**，而不是一开始就上生产级架构。

---

## 1. 认证：PyJWT + bcrypt（而不是 python-jose + passlib）

| 项 | 说明 |
|----|------|
| 为什么换 | `python-jose` 维护已停滞，历史上出过安全告警；`passlib` 与 `bcrypt 4.x` 存在已知的兼容性报错（`AttributeError: module 'bcrypt' has no attribute '__about__'`），新手很容易卡在这里 |
| 换来什么 | 依赖更少、报错更少，行为更可预期 |
| 注意点 | bcrypt 只处理前 72 字节，本项目在 `app/core/security.py` 里统一截断，并限制密码最长 64 字符 |

## 2. 数据库：默认 SQLite，可一行切换到 PostgreSQL

- 用 SQLAlchemy 建模，业务代码不写数据库方言；
- `.env` 里把 `DATABASE_URL` 换成 `postgresql+psycopg://...` 即可切换（需额外安装 `psycopg[binary]`）；
- 为什么默认 SQLite：个人开发阶段"零安装、免运维"的价值远大于并发性能；
- 什么情况下必须换 PostgreSQL：多用户高并发写入、需要连接池与更细的锁语义、需要复杂 JSON 查询时。

## 3. 缓存 / 在线状态：先用进程内状态，Redis 留给"广播"

原方案把 Redis 用于三处：房间状态、在线用户、Agent 对话记忆。本项目的处理是：

| 用途 | MVP 做法 | 上量后 |
|------|----------|--------|
| 在线用户 / 房间状态 | WebSocket 连接对象本身（内存字典）+ 数据库 `last_seen` 兜底 | Redis Pub/Sub 做跨实例广播 |
| Agent 对话记忆 | 关键内容落库（`agent_messages`），只取最近 6 条做上下文 | Redis 存最近 N 轮，数据库存长期 |
| 排行 / 统计 | SQL 聚合 + 索引 | 数据量上来再考虑 Redis ZSET 或物化视图 |

**关键认知**：Redis 真正不可替代的价值是**跨进程广播**，而不是"存个在线列表"。单进程时内存字典又快又准。

## 4. AI：直接调 OpenAI 兼容接口，不引入 LangChain

- 本项目只有 4 个轻量智能体（陪伴 / 报告 / 计划 / 氛围），每个都是"拼 prompt → 取回复"；
- 引入 LangChain 会带来大量间接依赖和版本冲突，收益在 MVP 阶段不明显；
- `app/agents/llm.py` 只做一件事：POST `/chat/completions`；
- 支持 `deepseek` / `qwen` / `glm` / `openai` / `ollama` 五种 provider，只改 `.env`；
- **无 Key 兜底**：`LLM_PROVIDER=mock` 或不配 `LLM_API_KEY` 时，全部走本地模板，功能仍可演示（响应里会标明 `source: template`）。

## 5. 计时：Web Worker + 服务端权威时长

- 前端：`workers/timerWorker.js` 基于 `Date.now()` 差值累加，后台标签页不被节流；
- 后端：`start_time` / `paused_total` / `paused_at` 落库，结束时长由服务端计算；
- 前端传来的秒数**一律不采信**，只用于界面展示；
- 恢复会话时由 `/api/sessions/active` 返回 `elapsed_seconds`，避免前端自行推导出错。

## 6. 白噪音：Web Audio API 实时合成

- 不下载、不打包任何音频文件：雨声 = 白噪声 + 低通；咖啡馆 = 粉噪声 + 带通；海浪 = 布朗噪声 + LFO 调制；
- 好处：零版权风险、零体积、可无限时长不循环卡顿；
- 限制：浏览器要求用户手势后才能播放，所以必须点击按钮启动。

## 7. 时间：数据库存 UTC，展示按用户本地时区

- 存储层统一 naive UTC，避免 SQLite / PostgreSQL 行为差异；
- "今日 / 本周 / 热力图"先用 `user.timezone` 换算成本地区间，再转 UTC 查询（`app/core/timeutil.py`）；
- 前端解析后端时间字符串时必须补 `Z`（`utils/format.js` 的 `parseUtc`），否则会有 8 小时偏差。

## 8. 部署：先本地，再单机 VPS

- 为什么不用 Vercel + Railway 免费方案：Vercel 免费版不能跑长连接后端；Railway 免费额度已基本取消；Render 免费实例休眠会直接掐断 WebSocket；
- 推荐路径：本机内测 → 一台 2C2G 轻量云服务器 + Nginx（配置 WebSocket 升级头与 `proxy_read_timeout`）；
- 前端 `npm run build` 后产物在 `frontend/dist`，后端启动时会自动托管（单进程部署最省事）。
